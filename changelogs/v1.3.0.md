# 织忆 V1.3「整经」

> 对应计划书 V1.3；插件包版本仍以 `metadata.yaml` 为准。

## ✨ 新增

- 完整 Agent 工具面：搜索、按 ID 获取、更新、列表、历史（创建工具已在 V1.2）。
- 命令 UX 补齐：保存、查看、修改、忘记、清空、关闭、状态、导出与群管理员命令。
- 最小只读管理：状态、统计、操作记录、导出。
- 检索调试日志：查询、作用域、候选、评分、过滤原因、最终注入与 Token。
- 部署者带外管理：群列表与群销毁，群解散后仍可用。
- 群状态与群注入显示预算截断条数。

## 🔄 变更

- Agent 工具只服务个人作用域；群聊调用个人工具直接拒绝。
- 工具写入来源标记为模型，用户命令写入仍为显式。
- 不提供忘记/清空工具；删除与清空只接受用户命令并二次确认。
- 调试日志默认不记录正文，默认保留 7 天。

## 🔧 修复

- 修复部分宿主下 Agent 写入工具无法落库的问题，写入恢复可用。
- 身份无法解析时工具与命令拒绝执行，避免越权。
- 工具失败返回明确错误，不阻塞聊天。

## 📌 说明

- 部分交付：只读工具、管理、诊断已补齐；私聊真实宿主烟测通过。
- 群聊、跨账号与第二账号隔离烟测待补。
- 群保存「固定英文标签+命令」体验被判定反直觉，仅中文别名与友好提示临时补丁。
- WebUI 与完整管理 API 未做。
