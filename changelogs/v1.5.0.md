# 织忆 V1.5「添线」

> 对应计划书 V1.5 与 ADR-0015；默认关闭，需用户逐项授权。

## ✨ 新增

- 个人私聊自动记忆提取（默认关闭）：用户逐项授权后，从私聊提取候选记忆，不直接变成事实。
- 分层授权：`capture`、`auto_extract`、`external_model`、`store_candidate` 分别授权；默认登记不包含这些授权。
- 候选命令：`/织忆 候选 列表/确认/拒绝`；候选产生时通知一次，失败不影响聊天。
- 敏感信息前置过滤：凭据、密码、身份证、银行卡等在进入模型前拦截或脱敏。
- 支持累计消息、回合结束、「记住这个」三种触发；任务幂等、可重试、可恢复。
- 群消息不捕获、不进入模型。

## 🔄 变更

- 推断记忆来源固定为 `INFERRED`，只能进入候选，用户确认后才参与检索。
- 候选过期只转归档，不物理删除；拒绝可记录原因。
- 提取失败不阻塞聊天，任务可重试并在重启后恢复。

## 🔧 修复

- 无面向用户的独立缺陷修复。

## 📌 说明

- 默认总开关关闭；未授权 `external_model` 时不外发，无本地模型兜底。
- 仅 Personal，群级自动提取未实现。
- 核心能力已实现；真实宿主模型调用、提取质量采集与阈值冻结仍待完成。
- 敏感内容泄漏率必须为 0，属于安全验收项。
