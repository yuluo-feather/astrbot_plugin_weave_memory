# 织忆 V1.7「接线」

> 对应计划书 V1.7 与 ADR-0017；导出不是备份，完整备份在 V1.8。

## ✨ 新增

- 导出格式 v2：每条记忆带稳定导出 ID、来源平台、来源记忆 ID、来源版本、导出时间与格式版本。
- 默认只导出 ACTIVE；`all` 附带归档/过期/被替换状态元数据（正文为空）；不导出候选与已删除内容。
- JSON 导入：走校验、去重、冲突、作用域与 consent 流程，只创建新记忆，不覆盖已有记忆。
- 导入 dry-run、断点续跑与回滚；回滚只删除本次导入新建的记忆。
- 群导入/导出命令与受控管理 API。
- 状态映射：仅 ACTIVE 导入为 ACTIVE；其余状态只导入审计元数据，不导入正文。
- Markdown 仅用于导出人读摘要，不能导入。

## 🔄 变更

- 导入忽略文件中的作用域、主体与内部序号，由服务端按调用者解析。
- 管理 API 新增 `GET /v1/export`、`POST /v1/import`，仅支持群作用域，是只读 API 的受控例外。
- 个人导入导出走命令；群导入导出需群管理员且群已启用并授权。

## 🔧 修复

- 重复导入同一文件按幂等键跳过，不重复写入。
- 防止伪造作用域字段越权导入；群导出文件不能导入个人作用域。
- 导入中断或失败可按本次新建清单回滚，避免残留。

## 📌 说明

- 核心已实现；个人命令链路与白名单群管理 API 宿主烟测通过。
- 群导入/群导出/群导入回滚命令待真实群管理员验证。
- 管理 API 要求非空 `api_admin_usernames` 白名单且 dashboard 用户名命中；个人作用域一律拒绝。
- 导出不是备份；完整备份与恢复在 V1.8。
