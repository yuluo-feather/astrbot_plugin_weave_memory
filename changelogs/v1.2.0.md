# 织忆 V1.2「锁边」

> 对应计划书 V1.2 与 ADR-0012；插件包版本仍以 `metadata.yaml` 为准。

## ✨ 新增

- Personal 默认登记：首次符合条件的私聊自动授权，仅告知一次。
- 持久 opt-out：`/织忆 关闭` 永久关闭并撤销授权；`/织忆 撤销授权` 可逆停止使用。
- 模型写入工具：用户明确提到长期偏好/背景/目标时可写入，来源标记为模型。
- 按作用域导出 JSON 与人读 Markdown。
- 操作审计：清空、关闭、删除等记录类型、作用域与结果，不记录正文。
- 两档删除：常规删除与彻底删除，彻底删除不保留可恢复正文。

## 🔄 变更

- 个人关闭改为永久 opt-out；清空只删数据，不重开已关闭作用域。
- 模型写入仅限私聊、仅限用户明确陈述，不保存完整聊天原文。
- 导出不是备份；完整备份与恢复留待 V1.8。
- 群数据保留期默认 90 天，到期只提示，不自动物理删除。

## 🔧 修复

- 删除级联补齐正文、版本、来源、索引与注入结果，修复「正文已删、索引仍命中」。
- 索引重建不复活已删除记忆；彻底删除不留可恢复正文。
- 清空/关闭后下一次检索不再返回旧记忆。
- 删除失败显式回报，可按维护任务重试。

## 📌 说明

- 默认开启自动登记与模型写入，可分别关闭回退逐用户授权。
- 默认登记只授予个人记忆，不授予捕获、自动提取或外部模型。
- 群记忆不参与个人默认登记，仍由管理员群开启。
- 导入未交付（V1.7）；完整备份恢复未交付（V1.8）。
