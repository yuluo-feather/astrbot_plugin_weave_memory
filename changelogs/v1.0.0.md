# 织忆 V1.0「初织」

> 对应计划书 V1.0；插件包版本仍以 `metadata.yaml` 为准。

## ✨ 新增

- 首个可用版本，在 AstrBot 中跑通「写入—存储—检索—注入—删除」闭环。
- 仅 Personal 个人作用域：私聊记忆只对本人可见，跨用户隔离。
- 显式写入：通过 `/织忆` 命令保存、查看、检索、忘记、清空、关闭。
- SQLite 全文检索，注入按 Token 预算与条数上限裁剪。
- 个人授权与生命周期：清空/关闭/删除按作用域执行，删除级联。
- 基础并发安全、热重载收尾与崩溃恢复，索引可重建。

## 🔄 变更

- 记忆正文作为不可信参考数据注入，不覆盖系统规则。
- 注入失败按「无记忆」处理，不阻塞聊天。
- 删除先写墓碑再清除正文与索引；关闭后停止写入与检索/注入。
- 个人记忆默认不进群，群共享留待下一版本。

## 🔧 修复

- 首个版本，无历史缺陷。
- 重复保存相同内容返回同一记忆 ID，不产生重复记录。
- 旧版本更新返回冲突，不静默覆盖。

## 📌 说明

- 本版仅 Personal；群共享、Agent 工具、导出、自动提取均未交付。
- 个人授权为「无授权即拒绝」，默认登记从 V1.2 起。
- 检索候选仅走全文索引，标签/时间候选与相关性阈值留后续。
- 开发验收通过，正式发布签署待定。
