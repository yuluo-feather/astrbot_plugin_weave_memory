# 织忆 V1.1「引线」

> 对应计划书 V1.1；插件包版本仍以 `metadata.yaml` 为准。

## ✨ 新增

- 群共享作用域：按群保存话题、约定、氛围与共同经历。
- 群管理员命令：群开启、群关闭、群清空、群销毁、群状态、群保存、群列表/查询。
- 管理员来源解析：优先平台群主/管理员角色，回退显式配置；无法判定时拒绝管理。
- 群注入独立预算，默认 192 Token、2 条记忆、8 条候选。
- 群解散后的部署者带外删除入口。
- 数据库 v4→v5 迁移与 v5→v4 回滚，支持 dry-run 预览。

## 🔄 变更

- 个人命令仅在私聊生效，群命令仅在群聊生效。
- 群关闭可逆，可重新开启并保留数据；个人关闭仍为永久。
- 群销毁必须先群关闭、二次确认并默认自动备份。
- 群状态对成员只读，不返回正文或管理员列表。

## 🔧 修复

- 读写强制按群作用域过滤，防止跨群与个人/群串读。
- 迁移前自动备份，备份失败中止升级。
- 管理员身份不接受用户传入参数，每次按命令发送者重新解析。

## 📌 说明

- 只做群级共享；Group personal、跨群共享、群导出、群级 Agent 工具未交付。
- 真实宿主群聊烟测未执行，待补。
- 群关闭可逆是本版特有差异，帮助与文档需与个人永久关闭区分。
- 群数据默认保留，完整保留期与自动清理在 V1.2。
