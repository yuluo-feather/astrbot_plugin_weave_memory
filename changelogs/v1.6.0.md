# 织忆 V1.6「候线」

> 对应计划书 V1.6 与 ADR-0016；本版只读管理 API，无 WebUI。

## ✨ 新增

- 候选管理：确认、拒绝、过期、归档；拒绝默认物理清除正文。
- 候选过期时间（默认 7 天），到期转归档，不物理删除。
- 只读管理 JSON API：概览、候选、记忆、历史与来源、群列表、检索调试、设置、维护状态。
- 按端点分权：实例级只读；群作用域需已启用且已授权；个人正文不经 API。
- 候选确认/拒绝/过期操作审计。
- 部署者命令：候选列表、维护状态、批量过期。

## 🔄 变更

- 候选确认/拒绝仅限用户命令，Agent 工具不能确认或拒绝。
- 管理 API 全部只读；设置写入仍走宿主配置页。
- 检索调试不更新访问时间、不写审计、不返回正文。

## 🔧 修复

- 拒绝候选默认清除正文，避免内容残留。
- 堵住管理 API 越权读取：群按启用与授权校验，个人作用域一律拒绝。
- 候选到期惰性归档，避免长期滞留。

## 📌 说明

- 核心实现并通过真实宿主烟测。
- 无 WebUI；本版只交付只读管理，编辑/删除/手动创建留 V2.1。
- 鉴权：所有端点需 dashboard 登录；配置 `api_admin_usernames` 后用白名单；个人作用域一律拒绝。
- 导入/导出未提前实现，留 V1.7。
