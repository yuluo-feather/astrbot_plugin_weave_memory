## 实现内容

- AstrBot 身份 Adapter：使用平台名、平台实例 ID、发送者 ID 建立 Personal Identity；群聊/缺失身份 fail-closed。
- Personal Scope：基于完整 Identity tuple 生成稳定 Scope ID；注入 hook 只查找已有 Scope，不为普通聊天自动创建记忆空间。
- Consent：schema v3 `memory_consents` append-only；默认拒绝；授权/撤销；撤销停止保存、主动检索和自动注入但不删除历史。
- 显式保存：`/记忆 保存 <内容>`，保存为 ACTIVE + Revision + Source。
- 查看/查询：`/记忆 列表`、`/记忆 查询 <问题>`。
- 删除/清空/关闭：命令带确认语义；删除/清空不可恢复，关闭保留数据但停止普通访问。
- 自动注入：`on_llm_request` + `extra_user_content_parts` + `TextPart.mark_as_temp()`；仅私聊、仅已有 Scope、仅授权用户、仅当前请求。
- 固定预算：最多 4 条，384 estimated tokens；预算估算包括上下文前后缀，且不依赖特定 Provider tokenizer。
- FTS 查询支持自然问句中的 CJK bigram/英文词匹配；结果仍受 scope/subject/status 过滤。
- 插件构建脚本生成自包含部署包，避免 AstrBot 只安装插件入口却找不到平台无关的 `core/`、`app/`、`adapters/` 包。
