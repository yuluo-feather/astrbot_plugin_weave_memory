# V0.2 领域核心实现报告

日期：2026-11-22
状态：实现完成，待阶段验收

## 实现内容

- 平台无关领域枚举和值对象：Identity、Scope、MemoryEntity、MemorySource、MemoryRevision、MemoryConsent。
- 时间输入要求带时区并统一转换 UTC。
- 内容归一化 v1 与去重键。
- 统一生命周期转换守卫及到期处理；候选 workflow TTL 与 ACTIVE 语义有效期分离；SUPERSEDED 恢复要求 USER/ADMIN 显式操作。
- Fail-closed ConsentPolicy。
- Clock、IdGenerator、MemoryStore Protocol。
- 仅供测试的 InMemoryMemoryStore：作用域过滤、活动/候选去重、乐观锁、Revision 记录。
- 领域核心位于 `core/`，不依赖 AstrBot 或 SQLite。
