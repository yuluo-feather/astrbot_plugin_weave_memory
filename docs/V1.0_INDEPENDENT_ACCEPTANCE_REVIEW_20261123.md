## 3. 独立代码审查结论

- **身份与权限边界**：Identity Adapter 只将可确认的私聊映射为 Personal；群聊、缺少身份 API 或身份字段为空时拒绝。SQLite 读取/写入同时限定 Scope 与 Subject；禁用 Scope 不可读写。
- **权威数据与索引**：Memory/Revision/Source 在权威事务内提交；FTS 独立同步并受持久 dirty marker 约束。dirty 状态下检索 fail-closed，启动恢复只从权威表重建 ACTIVE 且启用 Scope 的数据。
- **并发与版本**：单进程写入由 Coordinator 串行化；更新同时使用 expected revision 和存储层条件更新，避免静默覆盖。多进程不在 V1.0 承诺范围内。
- **生命周期**：删除/清空在事务中清理正文关联、关系边并记录不含正文的审计；关闭先禁用 Scope，再追加 Consent 撤销，撤销记录失败时仍保持 fail-closed。
- **注入安全**：记忆正文作为不可信文本转义；临时 TextPart 注入；普通异常隔离，取消信号不吞掉。Token 数是 provider-neutral 估算，不是 Provider tokenizer 精确值。
- **资源收尾**：Coordinator 先等待锁并关闭，再关闭 SQLite 连接；未发现跨进程锁或后台任务恢复被虚假宣称的情况。
