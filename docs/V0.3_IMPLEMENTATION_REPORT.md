# V0.3 SQLite + FTS5 实现报告

日期：2026-11-22
状态：实现完成，待阶段验收

## 实现内容

- `SQLiteDatabase`：单连接、外键、WAL、FULL synchronous、busy timeout、事务和 schema migration。
- `001_initial.sql`：八类权威表及 FTS5 虚拟表；schema version 1。
- `SQLiteMemoryStore`：Scope 创建/读取，Memory 创建/读取/列表/乐观锁更新。
- Memory、初始 Revision、Source 同一事务写入。
- 完全相同的 create 请求（稳定 ID 与字段一致）幂等；同 ID 不同 payload 冲突。
- ACTIVE/CANDIDATE partial unique index。
- `SQLiteFTSIndex`：增量同步、dirty 状态、fail-closed 查询、全量重建。
- CJK 字符边界索引化，支持中文局部短语检索；权威正文不被改写。
- 开发/测试用 rollback-to-empty-schema。

## 一致性设计

权威事务提交时将 memory ID 写入 `memory_meta.fts_dirty_ids`。FTS 同步在独立事务完成并移除对应 dirty 标记。索引同步失败时，权威正文、Revision、Source 保留，dirty 标记不清除；dirty 集合非空时所有 FTS 查询拒绝执行。全量 rebuild 在一个事务中重建 ACTIVE 索引并清空 dirty 集合。
