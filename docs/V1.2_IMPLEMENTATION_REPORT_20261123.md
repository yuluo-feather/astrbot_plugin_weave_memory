# V1.2「锁边」默认登记实现报告（2026-11-23）

状态：代码、测试与 dev docs 完成；真实宿主首次告知/工具写入烟测未执行；计划书已由羽忆侧修订（11 份）。
测试：157 passed；ruff 全绿；mypy 39 source files；compileall 与插件包构建通过。

## 1. 实现内容

- ADR-0012：Personal 默认登记 + opt-out。
- `ConsentService.ensure_auto_enrolled`：仅在 scope 启用且无 consent 历史时追加 `GRANTED`（`source=auto_enroll`）；已有 `GRANTED`/`REVOKED` 不改写。
- `AstrBotMemoryInjector`：私聊首次符合条件的请求自动创建 scope、登记 consent，并 `event.send` 一次固定告知；告知失败不影响聊天；`auto_enroll=false` 时回到原有显式授权路径。
- `MemoryApplicationService.save_agent`：模型工具写入路径，来源 `AGENT`，沿用去重、Revision/Source、WriteCoordinator 与 Consent guard。
- `AstrBotMemoryCommands.remember` + `main.py` 的 `weave_memory_remember` 工具：仅在用户明确提到长期偏好/背景/目标时调用；拒绝群聊、撤销/关闭、空内容与非法类型。
- `app/export.py` + `MemoryApplicationService.export_personal` + `GroupMemoryService.export_group`：按作用域导出 JSON/Markdown；个人受 consent 约束，群导出需管理员；不含其他用户。命令 UX 留到 V1.3。
- `memory_operations.metadata_json` 默认写 `result=SUCCESS`；不含正文。失败仍以类型化异常/日志呈现；V1.8 再引入 ledger 级 result。
- 注入无缓存；删除/清空/关闭后下一次注入不出现旧记忆（新增回归测试）。
- `_conf_schema.json`：新增 `auto_enroll`（默认 true）与 `agent_write_enabled`（默认 true）。
- README/metadata：默认开启、opt-out、一次性告知、工具写入与配置项同步。

## 2. 语义

- `/织忆 撤销授权` 与 `/织忆 关闭` 是持久 opt-out；`/织忆 清空` 只删数据，不重新开启已关闭 scope。
- 群共享记忆仍由管理员 `/织忆 群开启` 控制，不参与个人 auto_enroll。
- 后台自动提取仍不在本版实现；V1.5 继续只产 `INFERRED` 候选，不自动升级 `ACTIVE`。

## 3. 测试

- 新增 10 项：auto_enroll 首次登记且只告知一次；auto_enroll=false 回到显式授权；agent 工具写入 AGENT 来源且撤销/群聊拒绝；agent_write_enabled=false 拒绝写入；命令入口无授权时自动登记；撤销后仍可执行 `/织忆 关闭`；个人导出按 scope/consent 且排除已删除；群导出需管理员且只导当前群；操作审计含 result 且不含正文；删除/清空后注入不复活。
