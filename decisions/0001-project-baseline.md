# ADR-0001：V0 项目基线与实施顺序

- 状态：Accepted（V0 项目基线已执行）
- 日期：2026-11-22

## 背景

项目当前无源码仓库。用户授权从零建立 `weave_memory_dev` 并启动 V0。原始 V0 与总计划书仍标记为待评审，且 V0.1 明确要求先冻结契约。

## 决策

1. 新建独立工作区，不复制羽忆或星羽塔罗运行时代码。
2. 将 13 份原始计划书与原始 RAR 作为只读基线保存在工作区根目录，不随 dev 仓库重复保存。
3. 先完成 V0.1 六份契约草案及评审，再进入 V0.2 代码实现。
4. 所有未由原计划明确的细节显式列为 OPEN，不擅自补成已批准事实。
5. V0 范围严格限定为 V0 计划书所列能力。

## 后果

当前仓库包含目录骨架和 V0.1 文档草案，不包含已实现的运行时代码。契约冻结前不声称 V0 已可运行。
